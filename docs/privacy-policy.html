OctaLink 개인정보처리방침

시행일: 2026-05-06 수 | 최신 개정: 2026-11-06 금 | 버전: 1.5

Unbound Apex Systems(이하 “회사”)가 제공하는 OctaLink(이하 “앱”)는 회원의 개인정보를 중요시하며, 「개인정보 보호법」 및 관계 법령에서 요구하는 사항을 준수합니다. 본 방침은 앱이 수집·이용·보관·파기하는 개인정보의 범위와 회원의 권리를 안내합니다. 서비스 이용 조건은 서비스 이용약관을 따릅니다.

요약: 본 앱은 체육관별로 나뉜 채널에서 운영되며, 회원 정보는 기본적으로 소속 체육관 안에서만 보입니다. 다만 교류전을 위해 이름·성별·체급·벨트·프로필 캐릭터·운동 시작 시기·교류전 전적이 다른 체육관 회원에게 공개됩니다(4번). 외부 기관에 회원 정보를 판매하지 않습니다.

2. 수집 및 이용 목적

  • 회원 식별 및 가입 승인 절차 운영 (가입 신청 → 운영진 승인)
  • 수업 출결 관리 및 출석률 산출
  • 실력 평가 워크플로 — 코치 입력(제안) → 관장 검토 → 확정 또는 반려, 벨트·코멘트 전달
  • 관내 대진표 운영, 매치 결과와 전적 누적
  • 교류전 운영 — 다른 체육관 회원 명단 제공, 신청·승인·일정·결과 기록
  • 커뮤니티 운영 — 게시물 공개, 멘션된 회원의 공개 승인 절차
  • AI 주간 루틴 생성 (베타 대상 회원이 요청한 경우)
  • 1:1 문의 답변
  • 교류 요청 집계 — 요청한 회원을 밝히지 않은 요청 수를 해당 체육관에 서비스를 소개할 때 활용
  • 수업 리마인더, 코멘트 도착, 교류전 진행 등 푸시 알림 발송
  • 앱 이용 통계 분석 및 서비스 개선
  • 법령 위반 사항 및 운영 분쟁 발생 시 대응

3. 보유 및 이용 기간

  • 회원 자격 유지 기간 동안 보유합니다.
  • 앱에서 탈퇴하면 이용이 중지되고, 다른 체육관에 공개되던 프로필(4번)은 즉시 삭제됩니다. 회원 정보(이름 등)와 운영 기록(출석·실력 평가·코멘트·전적)은 같은 카카오 계정으로 다시 가입할 때 복구할 수 있도록 보존합니다. 삭제를 요청하면 지체 없이 파기합니다.
  • 카카오 계정 연결을 해제하면 탈퇴로 처리되고, 이메일·성별 등 카카오 동의 항목과 관련된 정보는 즉시 자동 삭제됩니다. 이름과 운영 기록은 위와 같이 보존하며, 요청 시 파기합니다.
  • 커뮤니티 게시물은 탈퇴해도 자동으로 삭제되지 않습니다. 탈퇴 전에 직접 삭제하거나 탈퇴 후 삭제를 요청할 수 있습니다.
  • 교류 요청은 회원이 요청을 취소하면 즉시 삭제됩니다.
  • Google Analytics 이용 기록은 Google Analytics 설정에 따른 기간(최대 14개월) 동안 보관됩니다.
  • 관계 법령(전자상거래법 등)에서 별도 보존 의무가 있는 경우 해당 기간 동안 분리 보관합니다.

6. 회원의 권리

  • 본인 개인정보의 열람, 정정, 삭제, 처리 정지 요구 (앱 설정 → 1:1 문의 또는 아래 이메일)
  • 푸시 알림 수신 동의 철회 (앱 설정 또는 OS 알림 설정)
  • 광고 ID 재설정·삭제 (기기 설정 → Google → 광고)
  • 카카오 동의 항목 개별 철회 — 카카오 계정 설정에서 이메일 동의를 해제하면 해당 정보가 자동 삭제됩니다 (회원 자격은 유지)
  • 카카오 계정 연결 해제 — 카카오 계정 → 연결된 서비스 관리 → OctaLink 연결 해제 시 탈퇴로 처리되고 이메일·성별 등이 자동 삭제됩니다
  • 회원 탈퇴 — 앱 설정에서 운영진 승인 없이 즉시 처리됩니다. 보존되는 정보의 삭제를 원하면 1:1 문의나 이메일로 요청하세요
  • 탈퇴 후 같은 카카오 계정으로 다시 로그인하면 재가입 절차가 진행되며, 보존된 운영 기록(출석·실력·코멘트 등)이 복구됩니다

7. 개인정보의 안전성 확보 조치

  • 전송 구간 TLS 암호화
  • 로그인 토큰은 카카오·Firebase SDK가 기기 안의 앱 전용 저장 공간에 보관
  • Firestore Security Rules 로 권한별 접근 제어 — 회원은 같은 체육관 정보만 조회하고 본인 정보만 수정, 관장은 소속 체육관 운영, 코치는 입력 제안, 다른 체육관에는 서버가 만든 공개 프로필(4번)만 노출
  • 운영진 역할(관장·코치) 부여는 앱 제작자(CREATOR)만 가능하며, 관장도 역할은 바꿀 수 없음
  • 카카오 계정 상태 알림은 카카오 공개키로 서명을 검증한 경우에만 처리
  • Cloud Functions 로그에 개인정보 출력 시 자동 마스킹 (이름은 첫 글자와 끝 글자만, 회원 ID는 앞뒤 3자리만)
  • 앱 서명 키 및 서버 자격 증명은 별도 격리된 보관소에 관리
