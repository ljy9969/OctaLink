# OctaLink 비공개 베타 모집 홍보영상 — 설계서

- **작성일:** 2026-07-21
- **작성자:** BlackCat Strike (이지연) / Unbound Apex Systems
- **상태:** 설계 확정 (구현 계획 대기)
- **대상 앱:** OctaLink (`com.unboundapex.octalink`) — Team Posse Striking 강남점 회원 전용 앱, Play Store 비공개 베타 진행 중

---

## 1. 목표 & 배경

OctaLink 비공개 베타 **테스터를 모집**하기 위한 **인스타그램 릴스용 30초 홍보영상**을 제작한다.
핵심 차별점인 **AI 코치 기능 2종**(실시간 쉐도우 피드백 · AI 맞춤 루틴)을 반드시 부각한다.

- **타겟 시청자:** Team Posse 강남점 회원 및 관심자 (격투기 입문자 중심)
- **핵심 메시지:** "AI 코치가 실시간으로 내 자세를 교정해주는 우리 체육관 앱"
- **행동 유도(CTA):** 비공개 테스터 참여 (프로필 링크)

## 2. 최종 결과물 (Deliverables)

- 포맷: **9:16 세로, 1080×1920, 30초, H.264 mp4, 30fps**, AAC 오디오
- **2개 버전** — 쉐도우 코치 구간(3–11초)만 교체, 나머지 타임라인 동일:
  - `octalink_promo_v1_overlay.mp4` — 앱 스켈레톤 + 실시간 피드백 오버레이 (AI 기능 직접 노출)
  - `octalink_promo_v2_raw.mp4` — 원본 촬영본 사용 (날것의 훈련 에너지)
- 회원이 두 버전을 비교해 최종 채택본을 고른다.

## 3. 스토리보드 (확정)

접근 방식: **AI 코치 히어로** — 두 AI 기능에 화면시간을 집중하고 나머지는 후반 몽타주로 압축.
컷 전환은 BGM 140 BPM 기준 **바 라인(≈1.71초)** 에 스냅한다.

| 구간 | 초 | 화면 | 자막(한국어) |
|---|---|---|---|
| 훅 | 0–2 | 원본 쉐도우복싱 클립, 첫 비트에 "탁" 임팩트 | **`내 자세가 맞는 걸까?`** |
| 전환 | 2–3 | 화이트 임팩트 → 앱으로 whip 전환 | (로고 살짝 노출) |
| **쉐도우 코치**(히어로) | 3–11 | 관절 스켈레톤 오버레이 + 실시간 피드백 팝업 + 점수 상승 | `AI가 실시간으로 자세 교정` / 팝업: `가드 올려!` `턱 내려` `회전 부족` |
| **AI 맞춤 루틴** | 11–16 | 주간 루틴 화면 스크롤 | `오늘 뭐 할지, AI가 짜준다` |
| 성장 | 16–20 | 프로필 헥사곤 차트 채워짐 + 승률 | `내 성장이 데이터로` |
| 소속감 몽타주 | 20–24 | 출석 체크인 · 커뮤니티 피드 · 토너먼트 브래킷 빠른 컷 | `출석·커뮤니티·토너먼트 한 곳에` |
| 로고 | 24–27 | Ink 배경에 옥타곤 로고 락업 | `OctaLink` |
| **CTA** | 27–30 | 로고 + 문구 | **`비공개 테스터 모집 中`** / **`프로필 링크로 참여`** |

> 초 경계값은 편집 시 가장 가까운 바/비트에 스냅한다(예: 3초 → 3.43초). 총 길이는 30.0초 고정.

## 4. 오디오 설계

- **BGM:** A안 트랩 비트 (140 BPM 하프타임, 808 킥 + 서브베이스 + 하이햇 롤 + 3박 스네어/클랩 + 어두운 마이너 플럭). 방향성 확정용 합성 미리듣기 존재(`promo_bgm_preview/octalink_bgm_A_trap.mp3`), **최종본은 30초로 재편성 + 마스터링**.
- **SFX:** 훅·전환·CTA에 펀치 임팩트 강조음. 자막 등장과 싱크.
- **믹스:** BGM -14 LUFS 목표, 트루피크 -1 dB. SFX는 순간 강조로 BGM 살짝 덕킹.
- (선택) 최종 채택 시 로열티프리 실제 트랙으로 교체 가능 — 저작권 안전한 소스만 사용.

## 5. 제작 파이프라인

### 5.1 화면 캡처 (에뮬레이터)
- Android Studio 에뮬레이터에서 앱 실행 후 `adb screenrecord`(또는 scrcpy 녹화)로 **1080×1920** 캡처.
- 캡처 화면: 홈, AI 맞춤 루틴, 프로필(헥사곤/승률), 출석 체크인, 커뮤니티 피드, 토너먼트 브래킷.
- 상태바 정리(demo mode) + KST 고정 + 알림 배너 차단.

### 5.2 쉐도우 코치 v1 (앱 오버레이)
- **OBS Virtual Camera**로 원본 쉐도우복싱 클립을 재생 → 에뮬레이터 카메라 입력(`webcam0`)으로 지정 → 앱이 해당 영상을 카메라 입력으로 받아 **MediaPipe 포즈 스켈레톤 + 실시간 피드백**을 오버레이 → 그 화면을 녹화.
- 원본 클립: `G:\내 드라이브\작업\개발\OctaLink\shadow_1782295922101.mp4` (720×1280, 63초, 무음).

### 5.3 쉐도우 코치 v2 (원본 촬영본)
- 위 원본 클립에서 **인물이 프레임에 꽉 차고 동작이 선명한 5~8초 구간** 선별.
- 스태빌라이즈 + 크롭 + 1080×1920 업스케일. 배경 인물/기구 노출 최소화되는 구간 우선.

### 5.4 조립 (ffmpeg)
- 각 소스 트리밍 → 비트 싱크 컷 리스트대로 배치 → 자막(ASS) 오버레이 → 전환(컷/화이트 플래시/whip) → 로고·CTA 카드 → 오디오 믹스 → 렌더.
- 공통 타임라인 1개 + 쉐도우 구간만 v1/v2 스왑하여 **2개 렌더 산출**.

## 6. 자막 · 브랜드 스타일

- 폰트: 한글 볼드 (Pretendard 또는 Noto Sans KR). 시스템 미존재 시 번들/다운로드.
- 컬러(디자인 시스템 준수): 배경 Ink `#0B0B0F`, 본문 Bone `#F5F2EC`, 강조 Blood `#C8102E`.
- 실시간 피드백 팝업은 Blood 계열 강조 pill. 로고는 `drawable-nodpi/mark_octalink.png` / `logo_octalink.png` 사용.
- **세이프 마진:** 상단 12% / 하단 20% (인스타 UI·프로필·좋아요 버튼 가림 방지).

## 8. 사전 준비물 · 리스크 · 폴백

| 항목 | 리스크 | 폴백/대응 |
|---|---|---|
| 앱 에뮬 실행 | 카카오 로그인 + Firebase 통과, 쉐도우 코치 베타 게이트 접근 필요 | 막히면 해당 화면을 **Play Store 스크린샷 24장**으로 대체 |

## 9. 완료 기준 (Acceptance Criteria)

1. `out/`에 **30.0초** 길이의 **1080×1920 H.264 mp4 2개**가 생성된다.
2. 두 영상 모두 **쉐도우 코치·AI 맞춤 루틴** 구간이 명확히 보인다.
3. 훅 자막 `내 자세가 맞는 걸까?`, CTA `비공개 테스터 모집 中` / `프로필 링크로 참여` 가 정확히 표기된다.
4. 컷 전환이 BGM 비트와 어긋나지 않는다(바 라인 스냅).
5. 자막이 인스타 세이프 마진 안에 있고 잘리지 않는다.
6. v1/v2 차이는 쉐도우 코치 구간뿐, 나머지는 동일하다.
