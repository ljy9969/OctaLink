## 이번 빌드에 포함된 변경

### 1) 다크 테마 카드(블럭) 구분 개선 — 회원 개선제안발, CEO 검토 승인
- 회원 1:1 문의: “다크 테마에서 카드 블럭 구분이 잘 안 돼요.”
- 원인: 다크 배경 Ink `#0B0B0F` 와 카드 surface Canvas `#15161B` 의 명도차 ≈4%뿐 + 보더/그림자 없음.
- 개선(공통 `PosseCard` 1곳만 수정 → **테마 적용 전 화면 자동 반영**):
  - 카드 surface `#15161B → #1E212B`(CanvasCard, 명도 상향)
  - 1dp 헤어라인 보더 `rgba(245,242,236,.09)`(Hairline)
  - 옅은 그림자 `shadowElevation 3dp`
  - **다크 테마에서만** 적용 — 라이트 테마(흰 카드)는 이미 구분되므로 변경 없음.
- 좌측 벨트/권한 색 스트라이프는 콘텐츠라 그대로 유지.
- 선(先) 디자인: Claude Design as-is/to-be 목업(전 22화면) → CEO 검토 승인 후 구현.

### 2) Q&A “작업 완료 안내” 답변 기능 (support → CEO → 운영자 게시)
- dev 태스크 완료 시 `node ops/engine/inquiry-flow.mjs done <문의id>` 실행하면:
  - support 에이전트가 “요청하신 개선을 반영했습니다” 류 완료 안내 초안 작성 → **CEO 검토(무조건)** → Firestore `inquiries.draftAnswer` 저장(DRAFTED).
- 어드민 “1:1 문의 관리”에서 **“작업 완료 안내 초안이 준비됐어요”** 로 사전 입력됨 → 운영자가 검토/수정 후 **게시**(ANSWERED).
- 이미 답변이 게시된 문의도 완료 안내 초안이 오면 미답변 배지에 다시 잡혀 운영자에게 노출.

### 3) 1:1 문의 답변 알림 (푸시) + 설정 토글
- 운영자가 문의에 **답변을 게시(status→ANSWERED)** 하면 문의 작성자에게 푸시 알림.
- 새 알림 타입 `INQUIRY_ANSWERED`("1:1 문의 답변", 기본 ON) — 설정 > 알림 설정에 **on/off 토글** 추가.
- 발송 경로: **Cloud Function `notifyOnInquiryAnswered`** (`onDocumentUpdated("inquiries/{id}")`, status *→ANSWERED 전이 트리거) → `sendNotificationTo([authorId], ...)`. 서버가 `members/{uid}.notificationPrefs.INQUIRY_ANSWERED` 를 읽어 OFF면 발송 skip(수신측도 재확인).
- 채널: `octalink_inquiry_answered`. 탭 시 앱 실행(딥링크 라우팅은 전 타입 공통 후속 과제).
- **⚠ 배포 필요**: 이 알림이 실제로 발송되려면 Cloud Function 배포가 있어야 함:
  ```
  firebase deploy --only functions:notifyOnInquiryAnswered --project octalink-28088
  ```
  (앱 APK만으로는 토글·수신 준비만 되고, 서버 함수 미배포 시 실제 푸시는 안 감.)

## 테스트 포커스 (확인 사항)
1. **다크 테마**: 홈·출석·커뮤니티·프로필·운영 등에서 카드가 배경과 또렷이 분리되는가(경계선/명도).
2. **라이트 테마**: 설정 > UI 테마에서 라이트 전환 시 기존과 동일한가(변화 없어야 정상).
3. **카드 모서리/그림자**: 카드 둥근 모서리 밖으로 콘텐츠·그림자가 잘리지 않는가(스트라이프 있는 카드 포함 — 커뮤니티/프로필/어드민).
4. **어드민 1:1 문의 관리**: 완료 안내 초안이 답변창에 사전 입력되고, “작업 완료 안내 초안이 준비됐어요” 안내가 뜨는가.
