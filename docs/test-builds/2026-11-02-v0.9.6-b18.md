## Play Console 출시 노트

build 17 을 아직 테스터에게 내보내지 않았어도 맞도록 교류전 지도 전체를 함께 적음.

```
<ko-KR>
교류전 상대 찾기 지도가 생겼어요.
- 우리 체육관 주변 1·2·3km 격투기 체육관을 카카오맵으로 확인
- OctaLink를 쓰는 체육관은 관원 목록에서 바로 교류전 신청
- 아직 OctaLink 전인 체육관에는 '교류 요청'을 남길 수 있어요
- 목록이나 지도에서 고른 체육관이 지도에 강조돼 위치를 바로 알 수 있어요
</ko-KR>
```

## 변경 (build 17 → 18)
- **고른 체육관 강조**: 상세 시트로 연 체육관 점을 일반 점(11dp)과 우리 체육관 점(18dp) 사이 크기(흰 테두리 포함 15dp)·진한 Ink 채움·옅은 후광으로 강조. 시트를 닫으면 원래대로.
- **지도로 스크롤**: 목록에서 체육관을 고르면 화면을 맨 위로 올려 시트 위로 지도(강조 점)가 보이게.
- **지도 위치 유지**: 원·카메라 맞춤은 반경이 바뀔 때만 — 체육관을 고를 때 사용자가 옮기거나 확대한 지도가 되돌아가지 않음.
