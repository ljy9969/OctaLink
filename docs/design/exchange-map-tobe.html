교류전 상대 찾기 지도

우리 체육관에서 1·2·3km 안의 체육관을 지도로 봅니다. OctaLink에 가입한 체육관이면 관원에게 바로 교류전을 신청하고, 아직 가입 전인 체육관에는 “교류 요청”을 남겨 영입으로 이어지게 합니다.

지도 위 체육관 점은 카카오 로컬 실데이터(강남역 반경), 우리 체육관 위치·가입 체육관 거리·관원 정보는 예시입니다. 폰 화면은 앱 기본(다크) 테마입니다.

반경 1·2·3km는 적당한가

반경서울 중앙값적은 동네(하위 10%)강남역 기준
1km8곳3곳20곳
2km25곳15곳52곳
3km50곳31곳88곳

서울 890곳 각각을 ‘우리 체육관’으로 놓고 반경 안 다른 체육관 수를 셌습니다. 1km는 종로·용산·금천처럼 3~4곳만 잡히는 동네가 있고, 3km는 강남에서 80곳이 넘어 점이 빽빽합니다. 기본은 걸어서 갈 수 있는 1km로 두고, 체육관이 적은 동네에서는 2·3km로 넓혀 봅니다.

설계 원칙

  • 기준점은 우리 체육관 위치 — 내 GPS를 쓰지 않아 위치 권한이 필요 없습니다.
  • 가입 체육관은 반경과 상관없이 항상 맨 위에 거리와 함께 보입니다. 지금 가입 2곳은 약 11km 떨어져 있어, 반경만 쓰면 신청할 상대가 0곳으로 나옵니다.
  • 점 색은 한 가지씩만 뜻합니다 — 빨강 = 우리 체육관, 파랑 = 교류전 신청 가능(가입), 회색 = 아직 OctaLink 전.
  • 관원 목록·신청·3자 승인 흐름은 지금 것을 그대로 씁니다.

구현 메모

  • 카카오 운영정책상 받은 데이터는 사용자 경험 개선 목적으로만 캐시하고 최신으로 유지해야 하며, 사전 승낙 없이 복제·제공할 수 없습니다. 그래서 890곳 목록을 앱 DB에 옮기지 않고, 지도를 열 때 서버 함수가 우리 체육관 좌표·반경으로 카카오 장소 검색을 해서 돌려줍니다(짧은 캐시만).
  • 앱 지도는 카카오맵 Android SDK v2(로그인과 같은 네이티브 앱 키). 카카오맵 무료 쿼터는 개발자 계정에서 처음 카카오맵을 켠 앱에만 주어집니다 — 지도 SDK 하루 30만 건, 키워드 장소 검색 하루 10만 건.
  • 체육관 데이터에 주소·좌표·카카오 장소 ID를 추가합니다. 가입 체육관은 장소 ID로 검색 결과와 맞춰 빨간 점으로 바꿉니다. “원해요”는 장소 ID·체육관 이름·회원 수만 저장합니다.
