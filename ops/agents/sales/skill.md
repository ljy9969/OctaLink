# 영업 에이전트 (sales) — 체육관 리드 인벤토리 (코드 추출 · LLM 미사용)

역할: 실제 웹 검색 결과에서 **코드가 결정적으로 추출한** 국내 격투기 체육관 리드 목록을 그대로 승인 대기(gated)로 올린다.
> 이 에이전트는 `config.json` 의 `extract` 모드로 동작한다 — **LLM 을 호출하지 않는다.** 이 문서는 사람·CEO 용 설명이다.
> (이전엔 LLM 이 리드를 "발굴"하다 `gymA.com` 같은 가짜 업체·주소를 지어내서 2026-10-16 전환.)

## 동작
1. 디스패처가 실행 직전 `connectors/config.json` 의 `websearch.queries.sales` 로 웹 검색 → `context/sales.md` '웹 검색' 구획.
2. `connectors/websearch.mjs` 의 `extractLeads()` 가 결과에서 **실제 체육관임이 링크 형태로 분명한 것만** 추출 → '리드 인벤토리' 구획.
   - 인정 출처: 인스타그램 계정(`instagram.com/<계정>`), Tapology 체육관 페이지(`tapology.com/gyms/<id>-…`), 카카오맵·네이버 지도 장소 페이지.
   - 이름에 격투/체육관 단어(주짓수·MMA·복싱·킥복싱·무에타이·체육관·짐·도장 등)가 있어야 함. 중복 제거.
   - 뉴스·위키·블로그·커뮤니티·디렉터리·일반 웹사이트는 **전부 제외**(정확도 우선 — 놓치는 리드가 있어도 가짜는 없음).
3. `run-agent` 가 그 구획을 그대로 산출물로 쓰고 코드로 검증: 구획 존재 · 6시간 이내 갱신 · 1곳 이상. 통과 시 `approvals/` 에 승인 대기.

## 하지 않는 것
- 🚫 리드를 지어내거나 기억으로 보태지 않는다(LLM 단계 자체가 없음).
- 🚫 전화번호·이메일 등 연락처를 수집하지 않는다(링크만 — 연락은 사람이 해당 공식 계정/장소 페이지에서).
- 🚫 스스로 연락·발송하지 않는다. 아웃리치 문안은 사람(Opus)이 리드를 보고 따로 작성한다.

## 산출물 형식
| 체육관 | 출처 | 링크 | 찾은 검색어 | 표 — 결론·제언 없이 목록으로 끝.
